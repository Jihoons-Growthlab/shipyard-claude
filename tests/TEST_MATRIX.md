# 테스트 매트릭스 / Definition of Done

## 단위 테스트

- F01: AUTH-T01~T07 (비밀번호 인증, 회원가입 중복, 미승인 로그인, OTP, 세션 로그아웃).
- F02: SHELL-T01~T05 + WEATHER-T01~T03 (메뉴, MDI 12개 제한, 탭 재사용/복원, 날씨 폴백).
- F03: DASH-T01~T06 (진척/대기/영향/월별 인도 지표).
- F04: HULL-T01~T08 (호선 CRUD, 마일스톤, 블록, cascade).
- F05: PLAN-T01~T09 (간트, DAG 순환, 게이트, 도면 연계).
- F06: PROG-T01~T06 (일별 UPSERT, 누적률, 완료/되돌림).
- F07: DWG-T01~T10 (Rev, PDF 30MiB, 샘플 구분, 도면 게이트).
- F08: APV-T01~T06 (순차 결재, 본인 결재, 반려, 배포).
- F09: USR-T01~T08 (관리자 권한, 승인/그룹, 본인 삭제 금지).

## 통합 시나리오 (목업의 강한 차별점)

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| E2E-01 | admin 로그인 → OTP → 대시보드 | 통과 후 메뉴/권한 정상 |
| E2E-02 | 신규 사용자 가입 → pending 로그인 거절 → admin 승인 → 로그인 | 승인 후 접근 가능 |
| E2E-03 | 신규 호선 → 블록 → 공정 → 필수 도면 연계(DRAFT) | 게이트가 READY를 막음 |
| E2E-04 | 도면 Rev0 결재 요청 → 검토 승인 → 승인자 승인 → 배포 | ISSUED, Plan gate 갱신 |
| E2E-05 | 공정 실적 40→100 저장 → 대시보드 집계 | DONE, 실제 종료일과 진척 갱신 |
| E2E-06 | Rev1 변경 후 배포, 이미 수행 중인 공정 있음 | 최근 개정 영향 목록 표시 |
| E2E-07 | 블록 삭제 | 관련 공정 삭제, 도면 자체는 유지/BlockId null |
| E2E-08 | 호선 삭제 | 하위 DB 관계/파일 고아 데이터 없음 |
| E2E-09 | VIEW 계정으로 프론트 버튼 숨김 우회해 직접 POST/DELETE | 403 |
| E2E-10 | 날씨 MCP 호출 실패 | 샘플 배지, LIVE 오표시 없음 |

## 완료 정의

- 지정 기능의 AC 성공; 직접 API 권한 거절 테스트 성공.
- 스키마 migration 및 재시드 가능, 수정 시 후방호환 고려.
- 새 코드만 targeted lint/test 실행; 전체 테스트는 통합단계.
- 원본 대비 의도적 변경은 `docs/handoffs/decisions.md`에 근거와 함께 기록.
- Skill 및 MCP 실제 사용을 과제 요건대로 **로그/사용 이력**으로 증명, 실행하지 않은 내용을 보고하지 않음.
