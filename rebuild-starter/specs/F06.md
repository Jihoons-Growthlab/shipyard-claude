# F06 공정 실적

이미지: progress. 권한: 조회 M22 View, 쓰기 M22 Write. 규칙 BR-03, 05.

## API

| 요청 | 응답 |
| --- | --- |
| `GET /api/progress-hulls` | `{hulls:[{hull_no,hull_nm,hull_status}],default_hull_no}`. 공정 있는 호선, 기본은 첫 BUILD |
| `GET /api/hulls/{no}/progress-targets?include_done=false` | `{hull_no,today,plans:[{plan_id,label,plan_start_dt,plan_end_dt,actual_start_dt,actual_end_dt,progress_rate,plan_status,manager_emp_no,manager_nm,drawing_wait}]}`. 기본 READY/WORK/DELAY, true면 전체. F05 정렬 |
| `GET /api/plans/{id}/progress` | `{plan,history:[{progress_id,plan_id,work_dt,progress_rate,man_hour,worker_cnt,worker_emp_no,worker_nm,remark,create_dt}]}` 작업일 내림차순 |
| `PUT /api/plans/{id}/progress/{work_dt}` | `{progress_rate,man_hour,worker_cnt,worker_emp_no,remark}` → 같은 형식 |
| `DELETE /api/progress/{id}` | 같은 형식 |

## 규칙

- 작업일 형식 오류 `작업일을 입력하세요.`, 기준일 초과 `미래 일자의 실적은 입력할 수 없습니다.`
- 진척률 필수 0~100 `진척률은 0~100 사이로 입력하세요.`
- 작업자는 승인 회원 `승인된 회원만 작업자로 지정할 수 있습니다.`
- 저장·삭제 후 BR-05, BR-03. 없으면 404 PROGRESS_NOT_FOUND.

## 화면

- 제목 `공정 실적 입력`, 설명 `착수 가능/진행/지연 공정의 일별 진척률·공수를 입력하면 공정 진척과 상태가 갱신됩니다.`
- 도구줄: 호선 select, `완료 공정 포함` 체크.
- 표: 공정, 계획기간(`시작 ~ 종료`), 실제착수, 진척(바), 상태, 담당. 행 클릭 선택. 빈 경우 `대상 공정이 없습니다.`
- 호선 변경 시 선택 해제. 미선택이면 `위 목록에서 공정을 선택하세요.`
- 상세 카드: 제목 라벨 + 오른쪽 상태 배지. 쓰기 권한 시 6열 폼: 작업일(기본 기준일, max), 누적 진척률(%)(기본 현재값, 0~100 step 1), 투입 공수(MH)(step .5), 투입 인원, 작업자(기본 로그인 사용자, `이름 (아이디)`, 빈 값 `-`), `실적 저장` / 비고(1칸).
- `실적 이력` 표: 작업일, 누적 진척률, 공수, 인원, 작업자, 비고, 삭제(쓰기). 빈 경우 `실적 이력이 없습니다.`
- 저장 토스트 `실적이 저장되었습니다.`, 100%면 `실적 저장 — 공정이 완료 처리되었습니다.` 삭제 확인 `실적을 삭제합니다.`, 토스트 `실적이 삭제되었습니다.`
- 저장 후 폼을 초기화하고 목록을 다시 불러온다.

## 수용 기준

PROG-T01 기본 목록·완료 포함. T02 같은 날 재저장 1건 유지. T03 마지막 날 누적률 사용. T04 미래일·범위 밖·빈 값 거절. T05 100% DONE·실제종료, 삭제 시 복귀. T06 View 쓰기 403.
