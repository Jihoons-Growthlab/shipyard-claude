# F04 호선

이미지: hull-list, hull-new, hull-info, hull-milestones, hull-blocks, hull-summary. 권한: 조회 M11 View, 쓰기 M11 Write.

## API

| 요청 | 비고 |
| --- | --- |
| `GET /api/hulls?status&ship_type&q` | 번호순. q는 번호+이름+선주 대소문자 무시 포함 검색 |
| `POST /api/hulls` | 201 |
| `GET·PATCH·DELETE /api/hulls/{no}` | DELETE 204. PATCH는 보낸 필드만 |
| `GET·PUT /api/hulls/{no}/milestones` | PUT `{items:[{milestone_cd,plan_dt,actual_dt}]}` |
| `GET·POST /api/hulls/{no}/blocks` | 201 |
| `DELETE /api/blocks/{id}` | 204 |
| `GET /api/hulls/{no}/summary` | |

호선 응답: hull_no, hull_nm, ship_type, hull_status, owner_nm, class_society, length_m, breadth_m, depth_m, dead_weight, dock_no, contract_dt, delivery_dt, remark, use_yn, create_user_id, create_dt, modify_user_id, modify_dt, plan_count, progress(공정 없으면 null), delay_count.

블록 응답: block_id, hull_no, block_cd, block_nm, block_type, parent_block_id, weight_ton, use_yn, plan_count, progress, drawing_count. 코드순.

일정 응답: milestone_cd, name, plan_dt, actual_dt, diff_days(둘 다 있을 때 실적-계획).

요약 응답: hull_no, plan_count, progress, plan_status{5상태}, drawing_count, drawing_status{ISSUED,APPROVED,REVIEW,DRAFT}.

## 규칙

| 오류 | message |
| --- | --- |
| 호선번호 없음 | 호선번호를 입력하세요. |
| 형식 `^[A-Za-z0-9._-]{1,20}$` | 호선번호는 영문/숫자/._- 1~20자입니다. |
| 중복 409 | 이미 존재하는 호선번호입니다. |
| 수정 시 변경 | 호선번호는 수정할 수 없습니다. |
| 코드 오류 | 허용되지 않는 코드값입니다. |
| 날짜 형식 | 날짜 형식(YYYY-MM-DD)이 올바르지 않습니다. |
| 인도 < 계약 | 인도 예정일이 계약일보다 빠릅니다. |
| 음수 치수·중량 | 0 이상의 값을 입력하세요. |
| 상태 비움 | 상태를 선택하세요. |
| 없음 404 HULL_NOT_FOUND | 호선을 찾을 수 없습니다. |

- 신규 기본값: PLAN, use_yn=true. 생성 시 일정 5개 CUT/KEEL/LAUNCH/TRIAL/DELIVER 생성, DELIVER 계획일만 인도 예정일. `CreateUserId`, `CreateDt=기준일`.
- 수정 시 `ModifyUserId`, `ModifyDt`.
- 일정: 코드 중복·미지원 400(`허용되지 않거나 중복된 일정 코드입니다.`). 날짜 순서 검사는 없다.
- 블록: 코드 필수(`블록코드를 입력하세요.`), 호선 내 유일(409 `이미 존재하는 블록코드입니다.`), 유형 BLOCKTYPE, 중량 0 이상. 삭제 후 BR-03 재계산, 없으면 404 BLOCK_NOT_FOUND.
- 호선 삭제는 BR-08.

## 목록

- 제목 설명 `행을 더블클릭하거나 [상세]를 누르면 호선 상세 팝업이 열립니다.`
- 필터 폼: 상태 전체, 선종 전체, `호선번호/호선명/선주`, 조회, 초기화. 오른쪽 `+ 호선 등록`(쓰기).
- 표: 호선번호(굵게), 호선명, 선종, 상태(b-info), 선주, 선급, 도크(`-`), 계약일, 인도예정, 진척률(바, 없으면 muted `계획 없음`), 지연(`-`), 상세. 행 클릭 선택, 더블클릭 상세. 아래 `총 N척`.

## 상세 모달

- 제목 `호선 {번호}` 또는 `호선 등록`. 3D 탭에서만 xl, 그 외 large. 제목 아래 12px muted로 상태명, 신규는 `신규 호선을 등록합니다.`
- 서브탭: 기본정보, 주요일정, 블록 구성, 연계 현황, 3D 보기. 신규는 탭 없음. 저장 후 신규는 해당 호선 상세로 전환. 재조회해도 현재 서브탭 유지.
- 서브탭 전환 시 데이터 탭은 재조회한다. 단 3D 탭에서 직전 데이터 탭으로 돌아올 때는 재조회하지 않는다.

**기본정보** 카드, 4열: 호선번호*(수정 시 readonly), 호선명(2칸), 선종 / 상태, 선주(2칸), 선급 / 전장(m), 선폭(m), 선심(m), 재화중량(DWT) / 도크/건조장소, 계약일, 인도 예정일, 사용여부(`사용` 체크) / 비고(전체). 하단 저장, 삭제(수정 시), 안내 `삭제 시 블록·공정·도면이 함께 삭제됩니다(FK CASCADE).` 조회 전용은 버튼 비활성. 삭제 확인 `호선 {번호} 및 하위 데이터(블록·공정·도면)를 모두 삭제합니다. 계속할까요?`

**주요일정** 카드: 일정, 계획일, 실적일, 차이(일). `일정 저장`.

**블록 구성** 카드: 블록코드, 블록명, 유형, 중량(ton), 진척(바 또는 `-`), 공정, 도면, 삭제. 빈 경우 `블록이 없습니다.` 아래 입력 줄: 블록코드 *, 블록명, 유형 선택, 중량(ton), `+ 블록 추가`. 삭제 확인 `블록과 해당 블록의 공정을 삭제합니다. (도면의 블록 연결은 해제)`

**연계 현황** 2열: 공정(`간트 보기` → plan-gantt, 이 호선), 전체 진척, 상태별 건수. 도면(`목록 보기` → dwg-list, 이 호선 필터), 상태별 건수. 없으면 `공정 계획이 없습니다.`, `도면이 없습니다.` 이동 후 모달을 닫는다.

토스트: 등록 `호선이 등록되었습니다.`, 저장 `저장되었습니다.`, 일정 `주요일정이 저장되었습니다.`, 블록 `블록이 추가되었습니다.`, 삭제 `삭제되었습니다.`

## 수용 기준

HULL-T01 필터·초기화·더블클릭. T02 중복·누락·날짜 역순 거절. T03 일정 5개, DELIVER 일치. T04 수정 후 목록 반영, 서브탭 유지. T05 블록 코드 호선 내 유일. T06 블록 삭제 시 도면 유지·BlockId null. T07 호선 삭제 후 고아 없음. T08 View 쓰기 403.
