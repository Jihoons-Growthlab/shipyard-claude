# F03 대시보드

이미지: dashboard. 권한: M00 View.

## API

`GET /api/dashboard/summary` 한 번으로 전부 받는다.

```text
today
kpi.{active_hulls,delay_plans,waiting_plans,pending_drawings} = {value, link:{screen,param?}}
hull_progress[] = {hull_no,hull_nm,progress,link}
plan_status[] = {status,count}          PLAN,READY,WORK,DONE,DELAY 순
drawing_disciplines[] = {discipline,name,total,counts:{ISSUED,APPROVED,REVIEW,DRAFT}}
deliveries[] = {month:'YYYY-MM',count,hull_nos}
delay_list, waiting_list, impact_list = {count, items(최대 6)}
```

- 대상 호선은 UseYN=1. 진행 호선은 DESIGN/BUILD/LAUNCH/TRIAL 수.
- 도면 대기는 PLAN이고 blocker 있는 공정, 시작일순. 항목에 `blockers:[도면번호]`.
- 결재·배포 대기는 REVIEW/APPROVED 도면 수.
- 분야는 코드 순서, 도면 없는 분야 제외.
- 공정 항목 `{plan_id,hull_no,label,plan_status,progress_rate,plan_start_dt,plan_end_dt,blockers,link:{screen:'plan-gantt',param:hull_no}}`.
- 영향 항목 `{drawing_id,drawing_no,rev_no,issue_dt,plan_id,plan_label,plan_status,hull_no,change_desc,link:{screen:'drawing',param:drawing_id}}`.

## 화면

제목 `대시보드`, 설명 `기준일 {today} · 호선/공정/도면 현황`.

- KPI 4열(gap 12): 진행 호선, 지연 공정(값 있으면 err), 도면 대기 공정, 결재·배포 대기 도면(값 있으면 warn). 라벨 12px muted, 값 26px 700. 호버 시 테두리 pri. 클릭 이동: hull-list, plan-gantt, plan-gantt, dwg-approval.
- 3열 ×2 + 1행:
  - 호선별 진척률: 격자 `130px 1fr 44px`, 라벨 말줄임, 바 14px, 굵은 `N%`. 행 클릭 → 그 호선 간트.
  - 공정 상태 분포: 120×120 SVG 도넛(r40, stroke 22), 가운데 합계·`전체`, 범례.
  - 분야별 도면 상태: 분야명(건수) + 16px 스택 바(0 제외), 아래 범례.
  - 월별 인도 예정: 높이 130px, 값 / 막대(최대 80px, navy2) / `YY-MM` / 호선번호.
  - 지연 공정: `{hull} {label}` / `N% · 계획종료 날짜`, b-bad 건수 배지. 없으면 `지연 공정이 없습니다.`
  - 도면 대기 공정: `착수 날짜 · 도면번호들`, b-warn. 없으면 `대기 중인 공정이 없습니다.`
  - 도면 개정 영향 공정(전체 폭): `{도면} Rev{n} → {라벨}` + 상태 배지 / `{사유} · 배포 날짜`, b-info. 없으면 `최근 개정된 도면의 영향 공정이 없습니다.` 클릭 시 도면 상세 모달.
- 색: 공정 PLAN #94a3b8, READY #0ea5e9, WORK #2563eb, DONE #16a34a, DELAY #dc2626. 도면 ISSUED #16a34a, APPROVED #0ea5e9, REVIEW #f59e0b, DRAFT #94a3b8.

## 수용 기준

DASH-T01 실적 100% 후 집계 갱신. T02 필수 도면 연계·배포로 대기 증감. T03 영향은 30일 + WORK/DONE/DELAY만. T04 월별 집계 일치. T05 KPI·행 이동 대상 일치. T06 7건 이상이어도 6건, 건수는 전체.
