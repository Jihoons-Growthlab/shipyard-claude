# F02 공통 셸·권한 메뉴·탭·날씨

이미지: dashboard, readonly-hull-list. 스타일: `ui.md`.

## API

- `GET /api/me/menu` → 볼 수 있는 메뉴 `[{menu_id,parent_id,title,token,seq,level,auth_gbn,can_write}]`. UseYN=1, 본인 등급 있음, 부모도 볼 수 있어야 포함. `can_write`는 level≥2.
- `POST /api/me/menu-access` `{menu_id}` → 204, `TB_SYS_LogMenuAccess` 기록. View 미만이면 403.
- `GET /api/weather?region=` (로그인 사용자) → `{region,source:"SAMPLE"|"LIVE",obsDt,tempC,condition,humidity,windMs,error}`. 지원 외 지역 400.

## 셸

- 진입 시 `me`와 `menu`를 불러온 뒤 렌더한다.
- 메뉴: 그룹 클릭 시 접기/펼치기, 말단 클릭 시 탭 열기, 현재 활성 탭의 메뉴 강조.
- 탭: 키 `${token}:${param??''}`, 최대 12개(`탭은 최대 12개까지 열 수 있습니다. 사용하지 않는 탭을 닫아주세요.`), 같은 키는 재사용, 닫으면 같은 위치의 다음 탭 활성, `다른 탭 닫기`.
- 탭 상태는 sessionStorage `swp_tabs`에 `{tabs:[{token,param}],active}`로 저장한다. 복구 시 현재 권한이 있는 화면만 남기고, 없으면 대시보드(없으면 첫 화면)를 연다.
- 새 탭을 열면 menu-access를 호출하고, 403이면 탭을 닫고 토스트를 띄운다.
- 탭 화면은 v-show로 유지해 필터·선택·스크롤을 보존한다.
- 화면 이동 함수 `navigate(token,param)`을 제공한다. 권한이 없으면 `해당 화면에 대한 권한이 없습니다.` 이미 열린 같은 탭이면 param 맥락을 다시 적용한다.
- 화면 토큰: dashboard, hull-list, plan-gantt, progress, dwg-list, dwg-approval, user-mgmt.
- 로그아웃: API 실패와 무관하게 세션·탭을 지우고 `/login`.
- 조회 전용: `can_write=false`면 제목 옆 `조회 전용` 배지를 표시하고 쓰기 UI를 숨기거나 비활성화한다.

## 날씨

- 위젯은 헤더에 있다. 지역 울산/거제/목포, 기본 울산, localStorage `swp_region`. 변경 시 저장 후 재조회, 10분마다 재조회.
- 공급자 레지스트리는 `WEATHER_PROVIDER` 이름으로 찾는다. 기본은 비어 있다. 없거나 실패·형식 오류면 SAMPLE이고 `error`에 사유를 넣는다. LIVE는 공급자 성공 시에만.
- 샘플: 울산 17.6℃ 맑음 52% 3.2m/s, 거제 18.9℃ 구름조금 61% 4.1m/s, 목포 16.2℃ 흐림 70% 5.0m/s. DB에 저장하지 않는다.
- 표시: 지역 select, 아이콘(맑☀️ 구름⛅ 흐☁️ 눈❄️ 비🌧️ 기본🌤️), `17.6℃`, 상태, `습도 N% · 바람 Nm/s`, 배지 `샘플`/`LIVE`. 조회 중 `날씨 조회 중…`, 실패 `날씨 조회 실패`.
- 로그아웃·지역 변경 뒤 늦게 온 응답은 버린다.
