# F05 공정 계획·간트

이미지: plan-gantt, plan-selected, plan-new, plan-drawing-wait. 권한: 조회 M21 View, 쓰기 M21 Write. 규칙 BR-01~04, 08.

## API

| 요청 | 비고 |
| --- | --- |
| `GET /api/procs` | 로그인 사용자. `{proc_cd,proc_nm,proc_group,std_days,seq}` |
| `GET /api/plan-hulls` | `{hull_no,hull_nm,plan_count}` |
| `GET /api/users/options` | 로그인 사용자. 승인 회원 `{emp_no,display_name}` 이름순 |
| `GET /api/hulls/{no}/plans?block_id` | `{hull_no,hull_progress,today,plans,deps}`. hull_progress는 필터와 무관, 공정 없으면 null |
| `POST /api/hulls/{no}/plans` | 201 |
| `GET·PATCH·DELETE /api/plans/{id}` | DELETE 204 |
| `PUT /api/plans/{id}/predecessors` | `{pred_plan_ids,confirm_late_preds}` |
| `GET·POST /api/plans/{id}/drawings` | POST `{drawing_id,required}` 201 |
| `DELETE /api/plans/{id}/drawings/{drawing_id}` | 204 |

공정 응답: plan_id, hull_no, block_id, block_cd, block_nm, proc_cd, proc_nm, label, plan_start_dt, plan_end_dt, actual_start_dt, actual_end_dt, progress_rate, plan_status, manager_emp_no, manager_nm, remark, create_user_id, create_dt, pred_plan_ids, gate_ok, blockers[{drawing_id,drawing_no,dwg_status}], drawing_wait(PLAN이고 blocker 있음).

정렬: 블록코드 숫자순(비숫자 뒤), 블록 없는 공정은 맨 뒤, 그다음 표준공정 Seq, PlanId.

연계 응답: `{plan_id,blockers,links:[{drawing_id,drawing_no,drawing_nm,dwg_status,has_issued,required,need_dt}],available:[같은 호선 미연계 도면]}`.

## 규칙

- 입력: `block_id, proc_cd, plan_start_dt, plan_end_dt, manager_emp_no, remark, pred_plan_ids, confirm_late_preds`. 신규 PLAN·진척 0.

| 조건 | message |
| --- | --- |
| 시작/종료 없음 | 계획 시작/종료일을 입력하세요. |
| 종료 < 시작 | 계획 종료일이 시작일보다 빠릅니다. |
| 다른 호선 블록 | 해당 호선의 블록이 아닙니다. |
| 공정 코드 | 허용되지 않는 공정 코드입니다. |
| 담당자 미승인 | 승인된 회원만 담당자로 지정할 수 있습니다. |
| 자기 참조 | 자기 자신을 선행 공정으로 지정할 수 없습니다. |
| 다른 호선 선행 | 선행 공정은 같은 호선의 공정이어야 합니다. |
| 순환 | 선행 공정이 순환 구조를 만듭니다. |
| 늦은 선행(409) | 선행 공정 종료일이 이 공정의 시작일보다 늦습니다. 그대로 저장할까요? |

- 수정은 진척·실제일을 보존한다.
- 연계: 같은 호선만(`같은 호선의 도면만 연계할 수 있습니다.`), 중복 409(`이미 연계된 도면입니다.`), `NeedDt=PlanStartDt`, 없으면 404 PLAN_NOT_FOUND·DRAWING_NOT_FOUND·LINK_NOT_FOUND.

## 화면

제목 설명 `막대 또는 좌측 공정명을 클릭하면 아래에 상세·수정 패널이 열립니다.` 화면은 높이 100%로, 간트가 남은 높이를 쓰고(min 140px) 패널이 아래 붙는다.

- 도구줄: 호선 select(기본: param 호선, 없으면 공정 있는 첫 호선), 블록 전체 select, 배율 select(축소 2.5 / 보통 4 / 확대 6 px/일, 기본 4), `호선 진척` + 170px 진척 바, 오른쪽 `+ 공정 추가`(쓰기).
- 호선 변경 시 블록·선택·스크롤을 초기화한다. 이동으로 들어온 param을 재적용한다.
- 범례(12px): 상태 5색(바 12×10px), `📐 도면 대기`, muted `— 선후행 연결선 / 빨간선 = 오늘({today})`. 바 색은 F03의 공정 색.

간트 계산:

- 시작 = min(오늘-5일, 공정 시작)이 속한 달의 1일. 끝 = max(오늘+5일, 공정 종료). 총 일수 = 끝-시작+8.
- 폭 = 230 + ceil(총 일수 × 배율). 행 높이 28px, 헤더 34px, 왼쪽 열 230px.
- 월 헤더 `YYYY.MM`(11px), 월 경계 점선. 왼쪽 열·헤더 sticky.
- 막대: 위 6px, 높이 16px, radius 3px, 트랙은 상태색 35%와 흰색 혼합, 내부 채움 = 진척 폭.
- 빨간 오늘선 2px, `오늘` 라벨. 처음 스크롤은 오늘선이 보이는 폭의 40% 위치.
- 선후행선: 선행 종료+1일 지점의 행 중앙 → 4단위 오른쪽 → 수직 → 후행 시작까지. 1px #64748b opacity .55. 막대·행 뒤로 클릭을 막지 않는다.
- 행: `블록코드` muted + 공정명, blocker 대기 행은 `📐`. 호선 전체 공정은 `호선`. 막대 title에 라벨·기간·진척·상태·도면 대기.
- 재조회·저장 후 가로 스크롤을 유지한다. 공정이 없으면 `표시할 공정이 없습니다.`

패널(카드):

- 머리: 라벨(또는 `공정 추가`), 상태 배지, `진척 N% · 실제 시작 ~ 종료`.
- 본문 `1fr 430px`, gap 16.
- 왼쪽 6열 폼: 블록(2), 공정, 계획 시작, 계획 종료, 담당자 / 선행 공정 (Ctrl 다중선택)(3, 높이 66), 비고(3, 높이 66). 하단 저장, 삭제, 닫기. 1560px 이하 4열: 블록(2), 공정(2) / 시작, 종료, 담당자(2) / 선행(2), 비고(2).
- 블록 옵션 `호선 전체(블록 없음)`, 담당자 옵션 `미지정`, 사용자 옵션 표기 `이름 (아이디)`.
- 신규 기본값: 현재 블록, CUT, 오늘 ~ 오늘+13일.
- 오른쪽: blocker 시 warn 박스 `📐 도면 대기: 필수 도면 {번호(상태)} 미배포 → 착수 불가`. 제목 `연계 도면 (필수 도면은 배포 전 착수 불가)`. 표 r3: 도면번호(링크 → 도면 상세 모달), 상태 배지 + `미배포`(b-warn), 필수/참고, `해제`. 빈 경우 `연계된 도면이 없습니다.` 아래 도면 선택, `필수`(기본 체크), `+ 연계`.
- 신규 공정 오른쪽: `저장한 뒤 이 공정에 도면을 연계할 수 있습니다.`
- 늦은 선행 409는 `confirm` 후 재전송, 취소하면 변경 없음.
- 삭제 확인 `공정을 삭제합니다. (실적·선후행·도면 연계 함께 삭제)`
- 토스트: `저장되었습니다.`, `삭제되었습니다.`, `도면이 연계되었습니다.`, `연계가 해제되었습니다.`, 미선택 `도면을 선택하세요.`
