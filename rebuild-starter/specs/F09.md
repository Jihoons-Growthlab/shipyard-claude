# F09 회원관리

이미지: users, users-new. 권한: 전 기능 M91 Admin. `/api/users/options`만 로그인 사용자.

## API

| 요청 | 비고 |
| --- | --- |
| `GET /api/users?status&q` | `{users,total,pending}`. created_at·emp_no순. q는 아이디+이름+이메일+전화 포함 검색. pending은 전체 건수 |
| `POST /api/users` | 201 |
| `GET·PATCH·DELETE /api/users/{emp_no}` | DELETE 204 |
| `POST /api/users/{emp_no}/approve` | `{groups:[코드]}` |
| `POST /api/users/{emp_no}/reject` | |
| `GET /api/auth-groups` | `[{code,name}]` |

사용자 응답: emp_no, last_name, first_name, display_name, email, phone, birth_date, status, totp_enabled, groups, created_at. `password_hash`, `totp_secret`은 응답에 절대 넣지 않는다.

## 규칙

- F01의 가입 검증을 재사용한다. 수정 시 아이디 검사 제외, 비밀번호는 입력했을 때만 8자 검사, 이메일·전화 중복은 본인 제외. status 값 검사(`허용되지 않는 상태입니다.`), 그룹 검사(`존재하지 않는 권한 그룹입니다.`).
- 신규 기본 status approved. `totp_enabled=true`면 409 `OTP_NOT_ENROLLED`.
- 수정: 아이디 변경 400(`아이디는 변경할 수 없습니다.`). secret 없는 사용자의 OTP 켜기 409. 끌 때 secret은 유지. `display_name` 재계산.
- 그룹은 단일 선택으로 기존 할당을 교체하고 비울 수 있다.
- 승인: pending만(409 `INVALID_STATUS` `승인 대기 상태가 아닙니다.`), 그룹 1개 이상 필수(`승인 시 권한 그룹을 1개 이상 지정하세요.`).
- 삭제: 본인 409 `SELF_DELETE` `로그인 중인 본인 계정은 삭제할 수 없습니다.` 그룹 할당은 CASCADE, 담당자·작성자·결재자·로그 참조는 SET NULL.
- 없으면 404 USER_NOT_FOUND `사용자를 찾을 수 없습니다.`

## 화면

상하 분할, 높이 100%, 위아래 각 1:1, 내부 스크롤. 제목 설명 `상단 목록 / 하단 입력·수정 (CRUD)`.

- 위: 상태 전체(승인대기/승인/반려/중지), `아이디/이름/이메일/전화`(Enter), 조회, 초기화, 오른쪽 `{total}명 · 승인대기 {pending}명`. 표: 아이디(굵게), 이름, 이메일, 전화번호, 생년월일, 상태 배지(대기 warn, 승인 ok, 반려 bad, 중지 기본), 2차인증(`사용`/`-`), 권한그룹(`-`), 가입일. 행 클릭 선택.
- 아래 카드 제목: `회원 수정 — {이름}`, `회원 등록`, 미선택 `입력 / 수정`(`목록에서 회원을 선택하거나 [신규]를 누르세요.`).
- 4열 폼: 성 *, 이름 *, 생년월일 *, 전화번호 * / 이메일 *(2), 아이디 *(수정 시 readonly), 비밀번호(`비밀번호 *` 또는 `비밀번호 (변경 시만 입력)`, placeholder `8자 이상`) / 상태, 권한 그룹(`없음`), 구글 2차인증(`사용 (등록된 사용자만)`), 가입일(readonly, 신규 `-`).
- 버튼: 신규, 저장, 삭제, pending 선택 시 `가입 승인`(btn ok).
- 본인 수정 후 세션·메뉴를 다시 불러온다. 본인 삭제는 클라이언트에서도 막는다. 삭제 확인 `회원 {아이디} 을(를) 삭제합니다.`
- 토스트: `저장되었습니다.`, `삭제되었습니다.`, `{이름} 님의 가입을 승인했습니다.`

## 수용 기준

USR-T01 필터·선택. T02 중복·형식·길이 거절. T03 비밀번호 빈 수정 시 해시 유지. T04 그룹 변경 즉시 반영. T05 승인 후 로그인. T06 본인 삭제 거절. T07 비ADMIN 403. T08 secret 비노출, 미등록 OTP 켜기 409.
