VIBE CODING ASSIGNMENT

조선소 통합관리 시스템 구현

1. 과제 개요

제공된 shipyard_mockup.html은 호선·공정·도면을 관리하는 단일 HTML 목업입니다. 데이터는 브라우저 localStorage에만 저장되고 업무 규칙도 모두 화면 JS 안에 있습니다. 이 목업의 기능을 FastAPI + Vue3 기반 3-tier 웹 시스템으로 구현하세요. Claude Code로 개발하며, 사용한 프롬프트와 토큰을 완료보고서에 남깁니다.

2. 조건

  1. 기능은 목업대로 동작해야 하며, UI/UX는 목업을 따라 하지 않고 자유롭게 개선해도 됩니다.
  2. Skill과 MCP를 반드시 사용하고, 완료보고서에 무엇을·왜·어디에 썼는지 기록합니다.
  3. FastAPI + Vue3 + SQLite 3-tier 구조로 개발합니다.
  4. 완료보고서에 입력한 프롬프트와 토큰 사용량을 기재합니다. (extract_usage.py로 추출)

3. 구현 범위

구분기능
필수 회원가입 → 관리자 승인 → 로그인(JWT), 권한그룹별 메뉴 접근 제어
호선 CRUD (마일스톤·블록 포함, 삭제 시 하위 데이터 함께 삭제)
공정 계획 CRUD, 선·후행 공정 연결(순환 연결 불가), 일별 실적 입력 → 진행률·상태 자동 계산
도면 CRUD, 개정(Rev) 이력, 2단계 결재, 배포
필수 업무 규칙은 서버에서 검증: ① 필수 연계 도면이 배포되지 않으면 공정 착수 불가 ② 권한 없는 사용자의 쓰기 요청은 거부(403) ③ 중복 아이디/이메일/전화번호 가입 불가
선택 대시보드(KPI·지연 공정), 공정 간트 화면, 도면 개정 영향 경고(최근 30일), 호선 상태 자동 전이, 2차 인증(OTP), 도면 PDF 업로드, 지역 날씨(MCP)

기준일은 목업과 같이 2026-10-19로 고정하고, 시드 데이터와 데모 계정(admin / park.pm / lee.dwg / han.wk / choi.qa)도 목업 것을 사용합니다.

  1. 작업을 마친 뒤 프로젝트 폴더에서 아래 명령을 실행합니다.
