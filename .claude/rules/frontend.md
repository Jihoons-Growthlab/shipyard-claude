# Frontend-only rules
- For UI creation or styling, read `reference/UiImages/README.md` and visually inspect the matching screenshots before changing code.
- Vue 3 Composition API; separate API client, components, and feature views.
- Preserve visible source workflow and state. All data is fetched/saved through API.
- Readonly UI improves UX but does not replace backend authorization.
- Avoid new chart/drag-drop/framework libraries unless acceptance criteria require them.
