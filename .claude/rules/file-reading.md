
# Token-Efficient File Reading

- Before exploring files, identify the current feature ID (F01-F09).
- Read the relevant feature specification in docs/features/ first.
- Read architecture documents only when the current task requires them.
- Search for filenames, symbols, or headings before reading large files.
- Prefer relevant sections over full-file reads.
- Inspect reference/shipyard_mockup.html only when specifications are insufficient or inconsistent.
- Reuse existing decisions and contracts instead of repeating analysis.
- Do not inspect unrelated feature directories.
- Do not repeatedly read unchanged files within the same task.
- Expand the reading scope when needed for correctness, security, integration, or testing.
- Avoid unnecessary MCP calls and redundant documentation lookups.
