# F02 공통 셸 · 권한 메뉴 · MDI 탭 · 날씨

- **OBS**: `renderHeader`~`renderTab`, `openModal`, `loadWeather` (628~794행).
- **DESIGN endpoints**: `GET /api/me/menu`, `GET /api/weather?region=울산|거제|목포`; 인증/권한은 F01.

## 기능 명세

| ID | 명세 | OBS 조건 |
|---|---|---|
| SHELL-01 | 상단 브랜드/사용자 표시/로그아웃 | display_name, 그룹명, TODAY 표시 |
| SHELL-02 | 권한 기반 메뉴 트리 | M00, M10/M11, M20/M21/M22, M30/M31/M33, M90/M91; UseYN·AuthGbn 반영 |
| SHELL-03 | 메뉴 접힘/펼침 | 그룹 클릭 시 열린 상태 반전 |
| SHELL-04 | MDI 탭 | 중복 화면+param 탭 재사용, 최대 12개, 선택·닫기·다른 탭 닫기 |
| SHELL-05 | 브라우저 세션 내 탭 복구 | 기존 탭 중 현재 권한 허용 화면만 복구; 없으면 대시보드 |
| SHELL-06 | 상세 모달 | 호선/도면은 MDI 탭이 아닌 팝업, Esc/닫기로 종료, 도면 기존 항목은 큰 모달 |
| SHELL-07 | 조회 전용 | View만 있으면 `data-w` 쓰기 버튼 disabled 및 '조회 전용' 표시 |
| SHELL-08 | 메뉴 접근 로그 | 신규 화면/모달 진입 때 `TB_SYS_LogMenuAccess` 기록 |
| WEATHER-01 | 지역 선택 | 울산/거제/목포, 기본 울산, 선택 지역 저장 |
| WEATHER-02 | 실시간 날씨 | 관측시각, 기온℃, 상태, 습도%, 풍속m/s; 지역 변경 및 10분마다 갱신 |
| WEATHER-03 | 실패 폴백 | 샘플 배지로 표시, 실시간(LIVE)과 명시적으로 구분, 날씨는 DB 미저장 |

## 날씨 응답 예시 (OBS 주석에 명시됨)

```json
{"region":"울산","obsDt":"2026-10-19T09:00","tempC":17.6,"condition":"맑음","humidity":52,"windMs":3.2}
```

- 원본 `WEATHER_API=''`이므로 **실제 MCP 호출은 구현되어 있지 않음**. API URL 예시만 존재.
- 날씨 샘플: 울산 17.6℃ 맑음 52% 3.2m/s, 거제 18.9℃ 구름조금 61% 4.1m/s, 목포 16.2℃ 흐림 70% 5.0m/s.
- 서버 어댑터가 실제 MCP 날씨 도구를 사용할 때 해당 도구/서버의 ID는 운영환경에서 확인 필요. **가상의 MCP 서버명을 만들어 설정하지 말 것**.
- 사용자가 로그아웃했거나 지역 변경 후 이전 응답이 늦게 도착하면 그 결과를 화면에 반영하지 않음.

## AC / 테스트

- SHELL-T01 권한 없는 메뉴는 보이지 않으며 직접 API 요청도 403.
- SHELL-T02 같은 화면/param을 두 번 클릭하면 탭은 하나.
- SHELL-T03 12개 탭 이후 추가 시 오류 토스트, 기존 탭 영향 없음.
- SHELL-T04 팝업은 Esc 및 닫기로 종료, 선택 후 이동 동작 보존.
- SHELL-T05 브라우저 내 탭 복구 시 권한없는 탭 배제.
- WEATHER-T01 3개 지역 선택 시 올바른 region으로 요청.
- WEATHER-T02 호출 실패 시 샘플로 표시하고 LIVE라는 허위 표기 금지.
- WEATHER-T03 로그아웃/지역변경 이후 늦은 응답은 무시.
