# 기능 명세 인덱스 — 작업 단위

각 작업에서 **이 파일과 해당 feature 한 개**를 우선 읽는다. 열거된 의존 문서만 필요할 때 추가로 읽는다. 모든 문서를 한번에 주입하지 않는다.

| ID | 화면/기능 | 화면 토큰 | 소스 범위 | 읽기 의존성 | 우선순위 |
|---|---|---|---|---|---|
| F01 | 인증/회원가입/OTP/세션 | login/signup/otp | 533~618 | 01-system, 02-data-model | P0 |
| F02 | 공통 셸/메뉴/탭/날씨 | shell/weather | 619~794 | 01-system, F01 권한 API | P0/P2 |
| F03 | 대시보드 | dashboard | 800~846 | 03-business-rules, F04~F08 결과 | P2 |
| F04 | 호선/주요일정/블록 | hull-list, hull-detail | 848~936 | 02-data-model, 03-business-rules | P0 |
| F05 | 공정 계획/간트/도면연계 | plan-gantt | 938~1052 | 03-business-rules, F04, F07 | P0 |
| F06 | 공정 실적 | progress | 1094~1133 | 03-business-rules, F05 | P1 |

| F08 | 2단계 도면 결재/배포 | dwg-approval | 1261~1285 | 03-business-rules, F07 | P1 |
| F09 | 회원관리/그룹/승인 | user-mgmt | 1286~1320 | F01, 02-data-model | P1 |

> 역할: F02 셸과 날씨는 논리적으로 분리하여 셸을 P0, 날씨 실제 MCP 연결을 P2로 구현 가능. F05 도면 게이트를 위한 F07 도면 레코드/연계 데이터 계약은 간소화 인터페이스로 먼저 정하고 뒤에서 완성한다.

## 권장 구현 순서 (의존성 최소화)

1. I00 기반: DB schema/seed, auth/RBAC, API 오류 공통 처리, Vue 셸 (F01 + F02 셸).
2. I01 호선/일정/블록 (F04).
3. I02 공정 계획/의존/간트 + 도면 게이트 연계 스텁 (F05).
4. I03 실적 입력·집계 (F06).
5. I04 도면/Rev/PDF/연계, 게이트 통합 (F07).
6. I05 결재·배포 (F08).
7. I06 회원관리 (F09).
8. I07 대시보드 집계 (F03).
9. I08 날씨 MCP/폴백 (F02 날씨) 및 통합 테스트.

## 소스·설계 구분

- `OBS`: 원본 JS에 존재하는 입력과 동작/검증.
- `DESIGN`: FastAPI 경로/DB 검증/보안 등 구현 제안.
- `OPEN`: 요구사항 미확정. `docs/handoffs/decisions.md`에서 결정.
